# SyncLab — Promotional Video Storyboard

A 60-second cinematic product video for LinkedIn launch. Record with **Screen Studio** (macOS) or **OBS + After Effects** (any OS).

---

## Video Specs

| Setting | Value |
|---------|-------|
| Resolution | 1920×1080 (16:9) |
| Frame Rate | 60fps |
| Background Music | Upbeat electronic/ambient, no vocals. Suggestions: "Sappheiros - Falling" or any Artlist.io "Tech/Corporate" track |
| Font (overlays) | Inter or SF Pro Display |
| Color Grade | Cool tones (slate/emerald), high contrast |

---

## Shot-by-Shot Breakdown

### Shot 1: The Hook (0:00–0:05)
**Visual:** Black screen. One line of code types itself in monospace font, character by character.
```
const collaboration = require('realtime');
```
**Audio:** Subtle keystroke sounds (mechanical keyboard).
**Transition:** Hard cut to black.

---

### Shot 2: Loading Screen Reveal (0:05–0:10)
**Visual:** Your actual loading screen animating. Logo pulses, slides left, "SyncLab" types in, subtitle fades.
**Camera:** Static. Let the animation breathe.
**Audio:** Soft whoosh as logo slides. Subtle "ding" when text appears.
**Transition:** Fade to app interface.

---

### Shot 3: The Workspace (0:10–0:18)
**Visual:** Full app view. Dark theme, sidebar open on Files tab, one file (`index.js`) visible. Clean, uncluttered.
**Camera:** Slow zoom-in (1.0x → 1.05x over 8s).
**Text Overlay (bottom-left):**
> "A workspace built for teams"

**Audio:** Ambient music fades in.
**Transition:** Smooth pan right.

---

### Shot 4: Multi-File Creation (0:18–0:26)
**Visual:** Click the + button. Create three files rapidly:
- `index.js`
- `utils.py`
- `README.md`

Show the file tree populating. Click between them — tabs switch, editor language modes change (JS → Python → Markdown).
**Camera:** Static, focused on sidebar + tabs.
**Text Overlay:**
> "Multiple files. One room."

---

### Shot 5: Real-Time Collaboration (0:26–0:38) ⭐ KEY SHOT
**Visual:** Split screen or side-by-side view (or video of two browser windows).
- Left window: User "Sarah" typing JavaScript code
- Right window: User "Alex" watching cursors move in real time
- Show floating cursor name tags (`Sarah`, `Alex`) moving simultaneously
- Show inline edits appearing char-by-char with zero lag

**Camera:** Split screen (50/50), thin 1px emerald border between them.
**Text Overlay:**
> "Zero lag. Real-time CRDT sync."

---

### Shot 6: In-Room Chat (0:38–0:44)
**Visual:** Open the Chat tab in the sidebar.
- Message types: "Hey Sarah, check line 12"
- Sarah responds: "Looks good! Running it now..."
- Show unread badge animation.

**Camera:** Close-up on sidebar chat panel.
**Text Overlay:**
> "Context stays where the code lives."

---

### Shot 7: Execution & History (0:44–0:52)
**Visual:**
- Click **Run** button. Bottom panel slides up: `fib(10) = 55` in 42ms.
- Click **History** tab. Show list of past runs with exit codes and execution times.
- Click **Re-run** on a Python execution — code swaps instantly.

**Camera:** Pan down to console, then left to sidebar.
**Text Overlay:**
> "Execute JS, Python, Java & C++ in isolated containers."

---

### Shot 8: Call to Action (0:52–1:00)
**Visual:** Dark screen. Centered logo + text:
```
SyncLab
Code together. In real time.

Try it now → editor.yourdomain.com
GitHub → github.com/Mdsinan09/collab-code-editor
```
**Audio:** Music swells to climax, then quiet echo fade out.
**Transition:** Fade to black.
